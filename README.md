# Smart Pantry Manager

Smart Pantry Manager is an Android application used to manage pantry ingredients and provide recipe suggestions.

## Features

- Add ingredients
- Edit ingredients
- Delete ingredients
- Store quantities and units
- Record expiry dates
- Input validation
- SQLite database storage
- Recipe suggestions
- Recipe details
- Settings for expiring-soon alerts
- Persistent settings

## Technologies

- Java
- Android Studio
- XML
- SQLite
- SharedPreferences
- Git
- GitHub

## Running the App

1. Open the project in Android Studio.
2. Wait for Gradle to finish syncing.
3. Select an emulator.
4. Click Run.
